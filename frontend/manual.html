Instructions manual

Back to Studio

Make your first Short

  1. Paste a video link

    Paste a YouTube link into the main field.

  2. Choose what to make

    Try Action at 3 and AI Transcript at 0 for a first run.

  3. Generate and open the job

    Click Generate Shorts. When the job says Done, play a clip and click DOWNLOAD.

More ways to use Studio

Find videos on YouTube

  1. Type a topic

    Search options appear as you type. Set upload date, duration, and how many videos to find. Check Creative Commons only to filter by that license.

  2. Pick the results

    Check the videos to use. Set Clips per video and add AI direction if you want all selected videos to focus on a particular kind of moment.

  3. Queue your picks

    Find it below Short design. It starts the jobs and clears the results. Cancel this search clears the results without queuing anything.

Choose a clip method
Most Replayed
Picks peaks in YouTube’s replay graph when available.
Action
Picks moments with sustained movement.
AI Transcript
Uses timed captions and your selected model to pick 15–150 second clips and write hooks, titles, and captions.
AI Ranking
Enter 2–5 to make one animated countdown. Highlights can run up to 40 seconds each, within a three-minute export.
Split into parts
Cuts the full video into three-minute parts and adds a part number to the hook.

Clip counts are targets. Set a method to 0 to skip it.

Set up AI Transcript or AI Ranking

  1. Open AI settings

    Hover over AI settings in the header. Choose Local model, OpenAI, Anthropic, or Google.

  2. Select the model

    For Bionic, start its API server and enter its local API URL. For a cloud provider, enter its API key. Click List models or type the exact model ID.

  3. Tell AI what to look for

    Try “close races with funny reactions.” Put game terms or names in Caption glossary to help Whisper spell them.

If the AI check fails, Studio can continue with other selected methods. With only AI methods selected, fix the connection or choose another method before queuing.

Set the look of your Shorts

  1. Open the editor

    Start with a preset. Video placement and aspect ratio change how the source sits inside the vertical Short.

  2. Style the text

    Choose captions and font. Type a hook and press Enter for a line break. For AI Ranking, the hook can serve as the countdown title.

  3. Adjust layers

    Select and unlock a layer to move or resize it. Drag layer rows to reorder them. Save the design to reuse it.

Use video folders and overlay timing

Choose + Video folder and select a folder of MP4 or WebM files. Position the first video in the preview. Studio shuffles the videos and uses each once per job before repeating.

First 4 seconds
Show the layer from 0:00 to 0:04.
Play once
Hide the video when it ends. With both timing boxes checked, it disappears at whichever comes first.
Pause main video 2s
Freeze the main footage and pause its audio while the overlay starts.
Remove green screen
Key out the green backdrop on export.
Mute video
Silence the uploaded layer’s audio.
Follow jobs and get your clips

  1. Watch progress

    Jobs show the current stage and elapsed time. Stop generating requests a stop for active work. Use Retry on a failed or stopped job.

  2. Download or delete

    Play the clips under Done. Check clips for bulk actions. Leave Export metadata checked to also download a title and caption text file for each clip.

  3. Change the look after export

    Open the editor from a finished job, change the design, and confirm the re-render. Studio reuses the source and saved picks.

Where are my files?

Studio keeps jobs and downloads inside its portable folder. Delete job removes that job’s clips and any source Studio downloaded for it.

Studio is unavailable

On the host PC, open Start.bat from the portable folder. Open Studio on port 57286 using the host PC’s LAN address if you’re on another device.
